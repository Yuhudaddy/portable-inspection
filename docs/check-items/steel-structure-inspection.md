# 鋼構施工複核｜檢查項目名稱

整理日期：2026-09-16

用途：提供所長與工程部門主管確認現有檢查項目是否足夠，並討論是否需要新增、刪除或調整名稱。

## 基礎螺栓／柱腳

1. 螺栓規格、數量與位置
2. 螺栓定位與偏心
3. 螺栓露出與螺紋保護
4. 鋼筋干涉與固定方式
5. 柱腳底板與標高
6. 無收縮灌漿與完成狀況

## 吊裝／臨時固定

1. 吊裝計畫與施工順序
2. 吊點、吊具與作業區
3. 臨時螺栓與固定
4. 構件穩定與垂直調整
5. 風雨及颱風應變
6. 吊裝完成放行

## 高強度螺栓

1. 螺栓等級、尺寸與數量
2. 接合面與墊片
3. 螺栓孔狀況
4. 初擰及終擰順序
5. 工具校驗與抽查
6. 終擰外觀與缺失閉合

## 現場銲接

1. 銲工資格與施工程序
2. 接頭組立與根隙
3. 銲接面清潔
4. 銲接環境與防護
5. 外觀檢查（VT）
6. 非破壞檢測與修補

## 安裝精度

1. 鋼柱垂直度
2. 柱軸線與相鄰柱偏移
3. 柱頂標高
4. 梁水平度與樓層標高
5. 累積偏差
6. 整體垂直度／放行
