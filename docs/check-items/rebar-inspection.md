# 鋼筋工程查驗｜檢查項目名稱

整理日期：2026-09-16

用途：提供所長與工程部門主管確認現有檢查項目是否足夠，並討論是否需要新增、刪除或調整名稱。

## 材料與施工前

1. 無輻射證明
2. 材料證明與爐號
3. 物理性檢驗
4. 化學性檢驗
5. 進場堆置與防鏽
6. 機械式續接器文件
7. 配筋圖與現場版本

## 鋼筋配置－柱

1. 主筋強度／號數／支數
2. X／Y 向配置
3. 水平淨間距 ch
4. 垂直淨間距 cv
5. 箍筋號數／間距／彎鉤
6. 腰筋配置
7. 間隔器與保護層

## 鋼筋配置－牆

1. 牆厚與筋號／間距
2. 搭接位置與長度
3. 柱牆、梁牆錨定
4. 間隔器與保護層
5. 開口補強筋
6. T 字／轉角補強筋
7. 牆壁預留筋
8. 誘導裂縫截斷

## 鋼筋配置－梁

1. 主筋強度／號數／支數
2. 箍筋與腰筋
3. 同層淨間距
4. 雙層鋼筋淨距
5. 搭接／伸展／彎鉤
6. 機械式續接位置
7. 梁側穿孔補強
8. 梁內配管介面

## 鋼筋配置－板

1. 板厚
2. 短向鋼筋號數／間距
3. 長向鋼筋號數／間距
4. 長短向配置方向
5. 搭接位置
6. 正彎矩鋼筋延伸
7. 保護層與間隔器
8. 角隅補強筋
9. 開口補強筋

## 鋼筋配置－基礎／地梁

1. 上下層主筋號數／支數
2. 箍筋／繫筋
3. 柱筋、牆筋錨定
4. 鋼筋淨間距
5. 底部與側面保護層
6. 開口／套管補強

## 接頭／保護層－柱

1. 主筋搭接與接頭位置
2. 主筋伸展與錨定
3. 保護層實測
4. 續接器扭力／試驗

## 接頭／保護層－牆

1. 水平／垂直筋搭接
2. 牆筋錨定
3. 牆筋保護層
4. 牆筋續接器

## 接頭／保護層－梁

1. 搭接與伸展長度
2. 機械式續接
3. 梁側與梁底保護層
4. 機電配管介面

## 接頭／保護層－板

1. 板筋搭接與錨定
2. 板筋保護層
3. 開口及角隅補強
4. 機電套管介面

## 接頭／保護層－基礎／地梁

1. 主筋搭接與伸展
2. 保護層與墊塊
3. 設備開口介面

## 澆置前放行

1. 配筋圖與現場版本一致
2. 材料文件已完成
3. 主筋與箍筋配置完成
4. 搭接／錨定／續接完成
5. 保護層與間隔器完成
6. 開口、套管與補強完成
7. 澆置面清潔完成
8. 廠商自主檢查完成
